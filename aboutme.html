About Me

Hey, I'm Setthawut

I'm participating in Hack Club's Macondo hackathon, and this site is my entry log for the event. I'm using it to document my progress and share the things I learn along the way.

I built this whole thing from scratch: no frameworks, no build step, just plain HTML, CSS and vanilla JavaScript. I even made my own web components for the cards, the nav bar, and the buttons because I wanted to actually understand how the web works instead of letting a library do it for me.

It started as a simple log and kind of grew from there. I added a counter, a coin flip, and a little Fun Tab to link everything together. The plan is to keep building it out until it feels finished. And yeah, the whole thing is on GitHub if you want to poke around the code.
